## ✦ Sobre o projeto

O **Optimus ERP** é um sistema integrado de gestão empresarial desenvolvido para **centralizar e automatizar os principais processos de uma organização**. O software abrange áreas como finanças, estoque, vendas, compras, produção e recursos humanos, permitindo uma **visão unificada do negócio**.

Em vez de cada setor trabalhar com informações separadas, a proposta de um ERP é reunir tudo em um único sistema, de modo que as áreas da empresa compartilhem os mesmos dados.

<br/>

## ✦ Funcionalidades

O menu principal reúne os módulos do sistema:

| Módulo | Descrição |
|---|---|
| 👥 **Gerenciar Pessoas** | Gestão do cadastro de pessoas |
| 📦 **Gerenciar Produtos** | Gestão do cadastro de produtos |
| 🧾 **Gerenciar Títulos** | Gestão de títulos financeiros |
| 🛒 **Listagem de Vendas** | Consulta das vendas realizadas |
| 💰 **Balanço Financeiro** | Visão consolidada das finanças |
| 📄 **Gerenciar Contratos** | Gestão de contratos |
| ⚙️ **Configurações do Sistema** | Ajustes gerais do sistema |
| 🔗 **Integração GovConnect** | Integração com o GovConnect |

**Recursos adicionais**

- 🔐 **Verificação em duas etapas (MFA)** com **Google Authenticator**, para reforçar a segurança do acesso
- 🌐 **Interface em dois idiomas**: Português e Español
- 👋 Tela de boas-vindas personalizada com o nome do usuário

<br/>

## ✦ Áreas abrangidas

O sistema foi pensado para cobrir as principais áreas de uma organização:

| Área | Escopo |
|---|---|
| 💰 **Finanças** | Processos financeiros da organização |
| 📦 **Estoque** | Controle dos itens armazenados |
| 🛒 **Vendas** | Processos de venda |
| 🧾 **Compras** | Processos de aquisição |
| 🏭 **Produção** | Processos produtivos |
| 👥 **Recursos humanos** | Gestão de pessoas |

## ✦ Contexto acadêmico

Trata-se de um **projeto acadêmico**, desenvolvido com o objetivo de aplicar na prática conceitos estudados na área de tecnologia da informação. Entre eles:

- **Modelagem de sistemas**: levantamento e representação das necessidades de uma organização
- **Desenvolvimento de software**: implementação do sistema em Java
- **Integração de módulos**: conexão entre as diferentes áreas do sistema

O projeto contribui para o aprendizado e a experiência dos envolvidos.
